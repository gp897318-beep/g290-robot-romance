A make.fun entry for **Robot Romance: One-Line Pickup Lines for AI**: a
program that writes one single-line joke pickup line, under 200 characters,
aimed at a robot or an AI. The line is the simulation angle — a million
simulations of a love life, and in every single one, the answer is yes.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` and checks it first against the
competition gate: 1–200 characters, one line, not only whitespace.

## Entry

`main.ts` holds the chosen line, validates the gate, and writes the result.
Nothing else is submitted: the line is the whole entry.
